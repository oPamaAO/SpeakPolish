Голосовой ввод для opencode — портативная папка
================================================

Что это: надиктовываешь текст голосом (кнопка F9), он распознаётся локально
и бесплатно, второй кнопкой превращается в чёткое ТЗ для ИИ-агента.

Установка другу:
  1. Распакуй эту папку куда удобно.
  2. Двойной клик по install.bat и отвечай на вопросы (ярлык да/нет, автозапуск да/нет).
  3. Всё: Python/библиотеки/модель поставятся сами, файлы лягут в папку конфига opencode.

Нужно: Windows 10/11, микрофон, интернет для установки (~2 ГБ один раз),
установленный opencode (https://opencode.ai).

Запуск: терминал ОТ АДМИНИСТРАТОРА (иначе не работают глобальные хоткеи):
  python %USERPROFILE%\.config\opencode\voice\voice.py
или ярлык с рабочего стола, если создал при установке.

Хоткеи: F9 — говорить/стоп (куски дописываются), Shift+F9 — продолжить,
Ctrl+F9 — заново, Ctrl+Shift+Space — полировать в ТЗ (заменяет текст в окне).
В любом чате opencode работает команда /polish.

Состав папки:
  install.bat / uninstall.bat — установка и удаление
  src\ — скрипт, настройки, словарь терминов, гайд README.md
  assets\ — агент-полировщик и команда /polish для opencode
  tools\ — helper для ярлыков

Удаление: запусти uninstall.bat из этой папки.
