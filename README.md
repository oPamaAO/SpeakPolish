# 🎙️ SpeakPolish — наговорил → получил идеальное ТЗ

Голосовой ввод и кнопка «сделай конфетку» для [opencode](https://opencode.ai).
Жмёшь `F9` — говоришь поток мыслей. Жмёшь хоткей — получаешь чёткое
структурированное ТЗ, готовое к отправке агенту. Всё локально, всё бесплатно.

---

## ✨ Фишки

- 🎤 **Диктовка локально на GPU** — Whisper `large-v3-turbo`, интернет не нужен, ничего никуда не утекает
- 🌍 **Русский + English в одном потоке** — автоопределение языка, пунктуация из коробки
- 🧠 **Кнопка-полировщик** — превращает сырой поток мыслей в ТЗ: Цель, Контекст, Задачи, Ожидаемый результат, Ограничения
- 📋 **Улучшатель из буфера** — выделил свой текст → `Ctrl+C` → `F10` → готово, без диктовки
- 🧹 **Анти-мусор из коробки** — вырезает «спокойную музыку», зацикливания и прочий бред, который Whisper дорисовывает на тишине
- ⌨️ **Глобальные хоткеи** — работают поверх любого окна, с авто-повышением прав
- 📦 **Установка одним файлом** — `install.bat` сам ставит Python-зависимости, качает модель и спрашивает про ярлык и автозапуск

---

## 🚀 Быстрый старт

1. Распакуй папку, двойной клик по **`install.bat`**, отвечай на вопросы (ярлык да/нет, автозапуск да/нет).
2. Запусти через ярлык **VoiceOpencode** (или терминалом от администратора: `python voice.py` из папки `voice`).
3. Открой любой чат opencode, нажми **`F9`** и говори.

> ⚠️ Хоткеи — глобальные, им нужны права администратора (иначе Windows не отдаёт
> нажатия из админ-окон). Ярлык повышает права сам, вручную — запускай из админ-терминала.

---

## ⌨️ Хоткеи

| Хоткей | Что делает |
|---|---|
| `F9` | 🎙️ Старт / стоп записи. Каждый кусок **дописывается** в черновик |
| `Shift+F9` | ➕ То же самое, явное «продолжить» |
| `Ctrl+F9` | 🗑️ Очистить черновик, начать заново |
| `Ctrl+Shift+Space` | ✨ Отполировать черновик → **заменяет** текст в окне ввода |
| `F10` | 📋 Отполировать текст из **буфера обмена** (для ручного текста) |

Плюс команда `/polish` в любом чате opencode — та же полировка внутри интерфейса.

## 🧩 Как это работает

```
[ F9, говоришь ] ──► микрофон (16 kHz)
                        │
                        ▼
              faster-whisper large-v3-turbo (GPU, локально)
                        │
                        ▼
        ┌─ обрезка тишины ─ анти-выдумки ─ фильтр повторов ─ словарь терминов
        ▼
   draft.txt (всё копится абзацами, открыт в VS Code — видно вживую)
                        │
         ┌──────────────┴──────────────┐
         │ Ctrl+Shift+Space            │ F10 (текст из буфера обмена)
         ▼                             ▼
   opencode run + строгие правила ──► «конфетка» заменяет текст в окне
   (бесплатная модель, инлайн-промпт, чистый JSON-вывод)
```

Два независимых тракта: **черновик диктовки** (`draft.txt`) и **буфер обмена** (ручной текст).
Не пересекаются, не конфликтуют.

## 🐛 Что было побеждено (истории с фронта)

- 🎵 **«Спокойная музыка» в конце записи** — фирменная галлюцинация Whisper на хвосте тишины.
  Теперь тишина обрезается по энергии *до* распознавания, плюс чёрный список фраз.
- 🔁 **Зацикливания** («у меня зашу, у меня зашу…») — фильтр повторов схлопывает в одно вхождение.
- 📄 **Снос длинных диктовок** — чистка выдумок когда-то вырезала «целое предложение»,
  а в тексте без точек это был почти весь текст. Теперь удаляется только сама фраза.
- 🔤 **«зAPIсь»** — словарь замен срабатывал внутри слов. Теперь только по границам целых слов.
- 🖥️ **Батники-установщики** — `cmd` не понимает UTF-8 без BOM: кириллица разваливалась в «команды».
  Все `.bat` теперь строго ASCII, русский живёт в README.
- 🖥️ **Ярлык не там** — стол бывает в OneDrive. Путь больше не хардкодится,
  а спрашивается у системы через .NET (работает везде).
- 🔇 **«Распозналась одна строчка»** — в 83-секундной записи речи было 2%.
  Теперь скрипт пишет уровень (`пик / доля речи`) и предупреждает, когда дело в микрофоне,
  а не в коде, плюс авто-усиление тихих записей.
- 🧩 **Преамбулы в результате** («полирую… вызываю подагента») — голосовой путь ушёл
  с делегирования на инлайн-правила + чистый JSON-вывод с фильтром служебных реплик.
- 📝 **Структура «как попало»** — теперь 6 разделов всегда, чужие заголовки запрещены,
  цитаты-тесткейсы дословно, пункты «проверю сам» не попадают в Задачи.

## ⚠️ Нюансы, которые остались (честно)

- Замена текста в окне — эмуляция клавиш (`End → Home → Shift+End → Shift+Up → Ctrl+V):
  перед ней кликни в поле ввода и не трогай клавиатуру 3 секунды. Если старый текст
  местами остался — результат уже в буфере: `Ctrl+A`, `Ctrl+V`.
- Не жми полировку, пока идёт генерация ответа — клавиши могут уйти мимо.
- Free-модели имеют лимиты; при отказе скрипт скажет вставить черновик в TUI и вызвать `/polish` там.
- Ручные правки прямо в чате в полировку черновика не попадают (источник — `draft.txt`).

## 🏆 Самые глобальные исправления

1. Диагностика вместо гаданий: архив сырых записей + уровень в консоли доказали,
   где теряется текст (микрофон vs код).
2. Чистки, которые не едят полезное: границы слов, удаление только фразы, схлопывание повторов.
3. Полировка без посредников: инлайн-правила вместо делегирования — конец преамбулам и вольной структуре.
4. Контекст неприкосновенен: лор, описания, эпитеты сохраняются полностью и усиливаются
   синонимами, а не вырезаются.
